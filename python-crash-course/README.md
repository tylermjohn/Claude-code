# Python Crash Course: Job-Ready in Under 20 Hours

A focused, practical curriculum designed to get you fluent in Python for professional work.

## Course Structure (18 hours total)

### Day 1: Fundamentals (6 hours)
- **Lesson 1.1**: Setup, Variables, and Data Types (1.5h)
- **Lesson 1.2**: Control Flow (if/else, loops) (1.5h)
- **Lesson 1.3**: Functions and Scope (1.5h)
- **Lesson 1.4**: Practice Problems (1.5h)

### Day 2: Data Structures & Practical Python (6 hours)
- **Lesson 2.1**: Lists and Tuples (1.5h)
- **Lesson 2.2**: Dictionaries and Sets (1.5h)
- **Lesson 2.3**: List Comprehensions and Iteration (1.5h)
- **Lesson 2.4**: Practice Problems (1.5h)

### Day 3: Professional Python (6 hours)
- **Lesson 3.1**: Working with Files and Errors (1.5h)
- **Lesson 3.2**: Object-Oriented Programming (2h)
- **Lesson 3.3**: Common Libraries (datetime, json, re) (1.5h)
- **Lesson 3.4**: Capstone Project (1h)

## How to Use This Course

1. **Work through lessons sequentially** - Each builds on previous concepts
2. **Type every example yourself** - Don't copy-paste, build muscle memory
3. **Complete all exercises** - Solutions provided, but try first
4. **Build the capstone project** - Demonstrates job-ready skills

## What You'll Be Able to Do After

- Write clean, readable Python code
- Work with data structures effectively
- Handle files and exceptions properly
- Use object-oriented programming
- Read and understand most Python code you encounter
- Complete technical interviews and assessments

## Setup Instructions

1. Install Python 3.8+ from [python.org](https://python.org)
2. Verify installation: `python3 --version`
3. Start with `lessons/day1/lesson1-1-basics.py`

## Tips for Success

- **Stay focused**: 3 x 6-hour sessions or 6 x 3-hour sessions work well
- **Practice actively**: Run code, make mistakes, fix them
- **Use the REPL**: Type `python3` in terminal for quick experiments
- **Google is your friend**: Learning to find answers is part of fluency

## Getting Started

Navigate to `lessons/day1/lesson1-1-basics.py` and start coding!
